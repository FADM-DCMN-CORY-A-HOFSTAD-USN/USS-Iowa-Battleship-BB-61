Summary:
This is the Battleship USS Missouri version 2!!!It's the exact same size and model as my first ship. There are many changes to this model including cut super structure sections for easier printing, RC motor mounts, and more.The only drawback to this version compared to the other version is the hull sections are joined so instead of 10 hull pieces, there are now 5 for a stronger hull. I tried my best to cut the super structures so they can be easier to print, but some of the pieces still may be tricky to print, so if I find a way or can update the files i will figure it out. This is the us Missouri battleship. the ship is in 177 scale and the ship is 5ft long 7in wide and 1 foot high.
